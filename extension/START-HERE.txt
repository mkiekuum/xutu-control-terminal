序图终端 v2.5.0

1. 解压到固定目录，在 Chrome/Edge 扩展管理页开启开发者模式，加载本文件所在文件夹。
2. 登录序图网站，打开插件。主界面直接提供使用帮助。
3. 写需求，复制提示词。新建/复杂任务先完成问卷，表达偏好也在问卷里。
4. 将 AI 在聊天中给出的完整 JSON 粘贴到指令框，核实方案后执行。
5. 主界面有撤销、重做、十批历史；更多里可复制网页/保存离线HTML。

本版已移除 CLI/本机宿主，无需 Node.js 或 API Key。
更新代码后需在浏览器重新加载扩展。原始网页与快照可能含私密内容，请妥善保存。
完整安装与验收：https://github.com/mkiekuum/xutu-control-terminal/releases/tag/v2.5.0
