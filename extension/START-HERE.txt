序图终端 v3.0.2
1. 解压 chrome.zip 到固定文件夹，里面应直接有 manifest.json。
2. Chrome 打开 chrome://extensions，开启开发者模式，加载已解压的扩展程序。
3. 登录序图网站，写需求 → 复制给 AI → 粘贴 JSON 并执行。帮助在首页。
4. 删除/恢复先核对差异；结果未知点“检查原请求”，不要重复写入。
5. 原目录覆盖更新后，在扩展管理页重新加载；没有自动安装保证。
无 CLI、Native Messaging、本地问卷或 AI API 设置。最近十批历史仅在原浏览器保存。
正式安装说明：https://github.com/mkiekuum/xutu-control-terminal/releases/latest

外部图纸：请向 AI 明确允许修改的范围。原分类节点与辅助点不同；不要为适配网站擅自改依赖。仅预览的 JSON 不会保存；图形一致不代表计算准确。
