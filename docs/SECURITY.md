# 安全和权属

本站保存页与下载源码只在工作区 audit/input/original，均排除发布。扩展全新实现，不捆绑公司原站代码。LICENSE 仅保留权利，尚未取得公司公开发布许可，不声明 MIT/开源授权。

只请求固定站点权限；JS 是独立高权限入口。扩展 UI 消息仅接收扩展页面，网页不能通过 postMessage 调用终端。CLI 使用当前用户 0700 目录、0600 Unix socket；同一操作系统用户的进程属于同一信任边界，不防本用户恶意进程。没有 TCP 监听。

命令只存 SHA256 签名；结果递归过滤常见敏感键，但字符串内嵌秘密无法保证清除。业务结果只保存本机，不上传；不要执行会返回令牌的脚本。日志留存/加密与完整敏感字符串过滤尚未实现。公开 Actions 不含账号 Secrets，不跑登录写测试。不可信 PR 不能接触凭据。
