# 数据边界与权限

仅固定序图站点与 GitHub 更新站点权限；保留 storage、scripting、userScripts，移除 nativeMessaging。UI 消息只接受本扩展 ui.html，网站不能用 postMessage 调用终端。JSON script.execute 仍依赖浏览器用户脚本许可和真实网站权限，任意脚本副作用不可保证恢复。

问卷、记住的表达习惯、历史快照在本机 IndexedDB 按 origin/actor 隔离；日志只在本机。普通结果递归去除常见敏感键，但不能保证字符串内嵌凭据被清除，不执行返回令牌的脚本。原始 DOM 按用户要求不脱敏，只在主动复制/导出时返回，不写日志、历史、云服务或 GitHub。

无需扩大网站权限或关闭版本检查。离线 HTML 移除活动内容并设置 CSP；原始 HTML 则保留原文，不适合作为安全离线阅读文件。复制的上下文/结果可能包含私密计划，应由使用者决定外发对象。

公开仓库不包含公司原站源码、真实账号/计划、浏览器配置或机器凭据。LICENSE 权属说明保持；本项目不宣称对第三方公司代码取得开放许可。测试采用合成数据；Actions 不跑带登录的生产写入。
