# AI 提示词与问卷

新建及复杂调整首轮必须 3–6 个有价值的问题，并保存到本地台账；仅改名等简单操作只问相关缺项。已答事实直接沿用，沉默和空输入不是同意。具体流程及门禁见 [V2.5_INTAKE_MANUAL.md](V2.5_INTAKE_MANUAL.md)。

复制提示词包含完整可读计划、版本、账号、真实项目组、分工、日期、基线、审核、进度、原生评分/计算、兼容报告、网站说明、命令契约与本地答复。当前计划作为新建参考不等于授权覆盖；新建不使用 plan.replace。账号或管理目标在读取期间变化则停止复制，避免混合上下文。

网站硬性约束、评分质量建议、个人表达偏好必须区分。表达与调整偏好仅在问卷选择，默认中性；明确记住后按账号和用途隔离，可修改/重置。节点为事件或成果是模型规则，喜欢简短成果名称则是表达选择。

信息充分后，AI 先给简短变更摘要，再在聊天正文给一个完整 JSON 代码块，不以附件/下载链接代替。未答完不能生成写入指令。AI 的提议工期必须展示给用户核实，不能把预测完成日期写作硬截止，不能为了分数改变真实业务。

外部 AI 仍可能答错；门禁确保形式、已答字段与具体提案一致，不保证模型真实理解所有业务。可只给建议而不输出写入。维护、升级和新设备配置不走业务问卷，按已授权范围独立执行；仅登录/浏览器强制许可等真实阻塞需本人完成。
