# 常见问题

- 提示先完成问卷：展开主界面问卷，保存必要答复，再复制给 AI。粘贴方案后核实人员和工期；AI 自称已确认不能替代本地确认。
- 日期不想设置：勾选明确暂不设置；空白输入会保持待问。
- 无项目组：核对当前账号登录，允许明确不分组；创建组必须由真实接口确认。
- 版本冲突：别人刚修改了网站内容。看最新差异，保留新增字段，不换编号重复执行旧快照。
- 部分成功：已完成步骤保留，未执行/失败分别列出。撤销不是跨计划事务。
- 结果未知：先读网站和历史，再决定保留现状，不盲目重发。历史 pending 不允许绕过。
- 历史不能撤销：账号/版本变化、存储失败或审核/分组/脚本不可逆。查看技术详情，不能清空日志来强行重试。
- 复制失败：完整内容在主界面底部手动复制区。DOM 可下载完整原文，离线阅读用独立离线 HTML。
- 更新检查失败：网络或 GitHub 状态未知，不能当最新版。稍后重新打开，或把复制的 AI 更新指令交给维护者。
- 看见旧版 CLI 按钮：浏览器仍加载旧代码，请在扩展管理页重新加载。v2.5 无 CLI/宿主入口。
