# v3.1.0 验收报告

## 已实现

- 首页保留需求、新建/管理、普通 AI 与 MCP AI、JSON 执行、结果、撤销重做与历史。移除使用帮助、重复步骤说明、MCP 地址/密钥输入框。
- 页面复制合为一处：默认顶层文字摘要；展开后完整 DOM、离线 HTML 和原文下载。保留范围、截断、资源缺失和失败信息，三者不再作为重复首页入口。
- 可选“侧栏仅点击展开”，默认关闭；开启后覆盖式显示，切换按钮、外部点击、Esc 和收起按钮均关闭；关闭开关恢复原样。不改变计划内容或网站计算。
- 本机 MCP 仅监听127.0.0.1，不部署公网。一次导入本机连接文件，绑定已选网页；普通 AI 提示词不带密钥，MCP 提示词按明确要求带 AI 密钥，不带浏览器桥密钥。
- 标准 HTTP MCP + stdio 适配器，注册 read/preview/execute/result 四项工具。复用正式命令及现有执行器：plan.batch、版本、请求去重、服务器回读与十批历史继续有效。
- 写入必须成功预览、绑定原指令与账号/网页、五分钟内提供明确同意原文。一个执行仅消费一次预览；未确认的派发不会自动重发。后台预览持久化，服务重启不会恢复或重放队列。

## 验证结果

174 项本地测试全部通过，0 跳过。包含原有业务、图纸转换、版本冲突、最小修改与历史恢复回归，以及本次侧栏事件、可逆卸载、密钥角色/Origin、请求队列去重、预览许可/过期/账号变化、持久化、导入校验、提示词分离和 UI 精简。

合成接口链路实际启动 HTTP 服务，通过扩展桥接原执行器：预览零写入，执行一次写入及回读，重复 execute 不重复提交。真实 stdio 子进程完成协议握手；不含生产计划。

隔离 headless Chrome 合成页面通过：使用本次读取的网站原生 fileSidebar 事件代码验证禁悬停、四种关闭及还原；JSON 单次提交、预览只读、图纸差异拒绝、12 项恢复/错误界面检查；MCP 提示词包含合成 AI 密钥且不含桥密钥，普通提示词无密钥。原始页面/离线快照完整性与离线无写入仍通过。未操作用户物理鼠标。

## 验证边界

没有在真实业务计划写入；隔离页面不是实际已安装扩展验收，也不是完整网站集成保证。当前工具无法控制 Codex 内置浏览器的扩展管理；需要用户重新加载扩展、授予可选本机访问权限并选取连接文件。未验证 Edge、真实系统剪贴板、多品牌 AI 的实际工具调用和跨电脑 SSH 隧道。

本机 Node 服务已完成独立握手；本次设备已配置 Codex MCP，但运行中的客户端需重启/重载后读取新配置与用户环境变量。此设备状态不作为他人安装成功的证明，不随发行包分发任何私有凭据。

AI 传入的 approval 文本不能独立证明人类同意；工具契约要求 AI 展示实际预览并等待使用者明确同意，不声称独立人工认证。MCP 不远程开放任意 script.execute 或完整 DOM 导出；原插件显式 JSON 脚本能力仍保留。云端 AI 往往不能访问 localhost；提示词携带密钥不等于自动添加工具。

## 发布与交付

沿用既有 workflow_dispatch 发布流程、chrome/source 两个 ZIP 和 SHA256SUMS。源码包含可选本机服务，插件包不含 Node 环境。自动更新仍核对官方 latest 发布页，不新增元数据服务、不自动安装。远端发布状态以工作流与发布页最终回读为准。
