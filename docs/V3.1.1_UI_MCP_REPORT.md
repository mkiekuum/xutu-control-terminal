本轮取代未发布的 v3.1.0 准备版本。v3.1.0 标签保留，发布工作流已取消，没有覆盖既有正式 Release。

## 当前实现

- 首页需求和执行两张统一卡片，按钮、间距、背景、字体统一；删除使用帮助和步骤教程。恢复、错误反馈及历史仍保留。
- “复制给 AI”保留原普通JSON流程；“复制给 MCP AI”直接生成独立随机连接密钥、绑定当前网页，并复制带精确私密配置及自主安装/启动/客户端配置/只读核验步骤的提示词。不再显示导入文件、地址或密钥输入表单。
- 按用户授权，MCP 提示词现在同时包含 AI 与浏览器桥密钥，供可信本机 AI 设置服务；普通提示词无连接密钥。复制内容不进入 Git/公开发布。无本机工具的聊天 AI 无法安装，提示词不等于已经连接。
- 兼容性功能继续自动检查、进入上下文和正式命令，界面入口隐藏。更新区仅显示短版本状态和必要按钮，后台详细报告保留用于维护提示词。
- 页面复制集中一处，默认文字摘要，高级选项保留完整DOM/离线HTML及范围反馈。左侧栏可选仅点击展开，四种关闭方式，可撤回原状。
- MCP 本机HTTP/stdio、预览授权、版本保护、防重派发和服务器回读；不部署公网。保留正式JSON、plan.batch和十批历史；不恢复旧业务CLI/Native Messaging/本地问卷。
