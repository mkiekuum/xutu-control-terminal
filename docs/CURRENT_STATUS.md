# AI 提问流程 v2.5.1

1. 在插件需求框写想做什么，复制提示词给任意 AI。
2. AI 在聊天中核实名称、日期、项目组、人员、工期及表达要求；复杂任务先问3–6个有价值的问题，简单改名只问相关缺项。已确认的信息不重复问。
3. 回答 AI，核实它提出的方案；请它直接在聊天正文给一个完整 JSON 代码块，不要文件链接。
4. 粘贴回插件，查看改动摘要并执行。插件保留参数、权限、版本、防重复、写后回读及批次历史保护。

没有本地问卷、长期偏好设置或“已核实方案”按钮，不要求 intakeId。表达习惯由你在 AI 对话中说明。插件不能技术性证明外部 AI 已提问，但会校验实际指令。

使用说明仍在主界面；网页导出、撤销/重做、历史对比保留。CLI仍已删除。

101项本地测试通过。真实网站写入、扩展重载和剪贴板未验证。旧本地台账不再读取或使用；不清除业务历史和去重数据。
