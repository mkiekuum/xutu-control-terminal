# 当前功能与边界（2.3.0）

主界面保留需求输入与 JSON 指令输入。“新建 / 管理”引导 AI，管理包括增删任务和各类已有操作；需求、详细上下文与规则一起复制。移除格式选择和界面 CLI/JavaScript 解析；原始 JSON、Markdown JSON 块、script.execute 及本机 CLI/后台能力保留。

本地 CLI 区仅测试、诊断复制和帮助。宿主新 ping 与真实 CLI 子进程经认证管道查询所选网页分别判定；无目标不执行，不扫描其他标签，不写业务；复制报告不含账号、计划、凭据、网页ID或本机路径。

自动检查 GitHub /releases/latest 发布网页，要求 HTTP 200 及本仓库有效版本跳转；404 页面不是发布。不调用版本 API 或读取版本文件。成功缓存2分钟、失败30秒并显示时间；失败不会冒称最新。AI 更新指令仅复制执行规范，不代表插件自行升级。新增固定 GitHub 官网主机读取权限，请求不附网站资料或凭据。

91 项本地测试通过，包含真实宿主/CLI/管道与模拟网页；当前已登录浏览器的新版重载与实际诊断仍待用户手动完成。未操作真实鼠标或写入网站计划。

2.2.1 历史：精简为两个输入框和主要按钮，其余收进“更多”；修复弹窗宽度规则，默认本地预览约 420 × 521 像素。发布页提供新手安装与更新说明。71 项本地测试通过；用户已安装 Chrome 的最终外观待重新加载后查看。

继承功能：详细AI资料与相关缺项问卷、聊天内可复制JSON、基础只读兼容检查、折叠复制报告、新版单页UI，以及维护升级/跨电脑手册。没有新增自动升级器、云同步、自动快照策略或定时服务。

2.2.0历史验证：71项本地测试通过；实际Windows浏览器经CLI返回2.2.0兼容报告，10项检查通过，site.context完整且含aiGuidance。新UI已通过实际本地浏览器渲染与DOM交互检查。本轮无网站业务写入，未创建测试计划。第三方AI本身是否遵循提示词仍需实际使用验证，不能保证任意模型绝不犯错。

提示词和CLI复制内容共用详细规则：先判断新建/修改与真实目标；只追问影响本次操作的负责人、执行人、日期、工期、资源及权限缺项，沿用已确认信息和允许的留空选择。信息充分后在聊天正文给单一完整JSON代码块，不以附件/下载链接代替。CLI context亦带相同规则和缺项摘要。

兼容性在打开插件、选择目标网页、连接CLI以及读取上下文时自动检查，也可手动刷新/复制。检查网页通信、7个定位锚点、会话、列表结构、原生计算合成样例、评分/完成率函数、可选用户脚本和宿主连接。报告脱敏，不附姓名/计划/本机路径。仅表示基础只读状态，不证明全部业务写入兼容或有权限；未自动扫描全部新增接口。

维护AI按GITHUB_MAINTENANCE.md/CROSS_DEVICE.md自主完成可执行流程，包括UI与功能代码更新；不发维护问卷。遇到登录、强制人工授权或超出既有授权的高风险操作才报告阻塞。业务计划信息不足时仍需问卷，两者不混用。

核心计划能力继承已记录实测。永久删除、完整历史、用户/角色管理无已核实可用接口；管理员正例、任务表写入、所有浏览器/新设备组合尚未验收。完整DOM写入回退、未知写入自动恢复、多目标selector和跨浏览器锁仍未完成。macOS暂缓。
