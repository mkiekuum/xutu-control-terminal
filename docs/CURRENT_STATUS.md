# 当前功能与边界（2.4.0）

本版增加局部批量改名、明确重编号、账号/场景隔离偏好、执行前摘要、冲突独立回读和真实版本传递。保留需求框、JSON/代码块输入、提示词复制、原业务命令、本机CLI及后台脚本能力；没有新增主机权限。

网站硬性约束、评分质量建议、个人偏好分别说明。偏好默认中性，未保存仅用于本次；用户点击“记住”才存于本浏览器，按网站登录actor和新建/管理场景隔离，存储键为哈希、值仅允许固定选项，不存计划/姓名正文/凭据。账号或场景变更后重新读取；旧scope不能写入另一账号偏好。

node.batchUpdate/node.renumber在最新快照上局部变换，经已有import接口单次版本保护提交。保留未改字段、布局及基线日期元数据；重编号同步端点/坐标/明确引用，不扫描替换普通数字。无法识别的基线引用结构会拒绝重编号。单次提交不等于已证明服务端事务，多步仍可能部分成功。

版本冲突一律不自动覆盖或重试；独立回读最新状态，报告拟改字段和可确认的差异。没有旧全文时明确不能判断全部冲突字段。onConflict的旧取值仍可解析，但不再授权盲目覆盖。target.versionFrom引用同计划前一成功且已回读步骤的真实版本。原requestId保留；缺省时界面按规范化JSON生成稳定编号；重放同作业不重复写入，未知结果保持未知。

106项本地测试通过（单元、JSDOM、模拟HTTP接口、真实本机宿主/CLI连接模拟网页）。本地浏览器只读预览已检查主界面。真实网站公开源码本次重新下载遇到TLS EOF；使用此前已核实契约，新命令的真实网站写入、Chrome加载后验证和同事新设备安装尚未验证。不操作真实鼠标，不修改生产计划。
