# 终端使用手册 v2.5

主界面：需求框、新建/管理、复制 AI 提示词、JSON 输入、改动摘要、执行结果、撤销/重做/历史。简短指引和详细使用帮助直接放在主界面。

输入只接受原始 JSON 或一个 Markdown JSON 代码块。独立 JavaScript、命令行、文件路径不能执行；显式 JSON script.execute 仍使用原浏览器用户脚本授权及校验，没有额外确认弹窗，AI 不得用它绕过正式参数契约。

新建与复杂调整先走 [问卷门禁](V2.5_INTAKE_MANUAL.md)，简单操作保持原有 JSON 流程。[字段规则](V2.5_PLAN_FIELDS.md) 区分计划负责人、执行人、开工、硬截止和分组。

[局部修改](LOCAL_EDITING.md) 保留无关字段；[历史](V2.5_UNDO_HISTORY.md) 是本机十个有效批次，不是原站全部编辑历史。跨计划恢复可能部分成功。预览/校验通过、服务器写入、写后回读、未知结果必须分别看待。

复制结果可能含私密业务资料，由使用者决定发给哪个 AI，不上传公开 Issue。更多里的兼容报告经过固定字段筛选，不含计划正文；[网页原文与离线文件](V2.5_HTML_EXPORT.md) 则明确未脱敏，只按用户主动操作生成。

本版无本机 xutu 命令、JSONL 文件执行或 Native Messaging 通道；既有 JSON 批次、context、后台执行器、权限、版本和计算逻辑保留。高级调用可使用 JSON 的 mode=preview/validate；主界面执行按钮按既有行为执行。
