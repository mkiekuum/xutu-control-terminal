# 新手：用自然语言操作序图

## 第一次使用

1. 按WINDOWS_INSTALL.md安装扩展。进入扩展终端，点“打开网站登录”，在序图自己完成登录，再点“检查登录状态”。这是打开官方登录流程，不是绕过密码或验证码。
2. 选择下面一种AI连接方式。网站账号与AI账号分别授权，不互换密码。
3. 输入“检查当前计划是否有重复依赖，保留编号和验收点”，生成结果后查看预览。想直接执行时勾选“生成后直接执行”。

## 方式A：插件内连接模型

展开“连接AI”，填写兼容Chat Completions接口的服务地址、模型名、API Key，点击授权并保存。地址通常带/v1，插件再加/chat/completions；具体以服务商文档为准。连接按钮保存配置，首次生成才验证服务和Key，不能把保存配置理解为模型测试成功。

支持HTTPS服务以及本机localhost/127.0.0.1模型。权限只在你点击授权时申请所填服务的origin。Key仅保存当前浏览器会话，关闭浏览器后需要重新输入。

默认只发送你输入的自然语言和命令契约，不读取业务内容。需要“修改当前计划”时，勾选“允许将当前计划内容发送给AI”；这会将当前计划名称、编号、节点、连线、人员字段等发送给你填的服务。请使用有权接收这些数据的服务。

AI生成的JSON经过本地校验，AI不能通过此入口生成任意JS执行。生成失败不会自动继续写入。仍可在独立JavaScript模式运行你自己提供的代码。

## 方式B：已有AI客户端通过MCP调用

适用于支持本地stdio MCP服务器的AI客户端。先安装Windows宿主，浏览器点击“连接本地CLI”，然后点击“复制外部AI接入配置”，把配置加入AI客户端的MCP设置。不同客户端的配置位置不同，此工具不会自动改写它们的配置。

配置不含网站Cookie、密码或AI Key。AI客户端启动本地node进程，通过标准MCP工具调用xutu_run，后者再连接已登录浏览器。所有操作仍受网站实际账号权限约束。默认禁止MCP脚本执行；需要时必须由用户在客户端启动参数显式加入--allow-scripts。

MCP提供契约资源xutu://contracts。建议在AI中说：“读取序图契约并检查能力，先定位计划编号，不要猜ID。保留编号及验收节点，删除冗余零耗时依赖前先给我预览。”

本地MCP不等于所有AI网站都能连接。只支持远程HTTP MCP的产品不能直接使用此stdio入口。

## 方式C：任意文本AI复制粘贴

输入需求后点“复制给其他AI的提示词”，粘贴到你使用的AI，再把它返回的JSON粘贴到终端。这种方式无需API Key；复制提示词不会自动附带网站数据。模型仍可能出错，执行器会拒绝未支持或不合法操作。

## 当前验证范围

已测试：合成AI响应解析、字段校验、脚本拦截、HTTPS/本机地址约束、Key不进入提示词、MCP真实stdio初始化/工具发现/契约读取。已验证MCP→本地宿主→已安装插件调用及核心浏览器业务链路。尚未测试：你的真实模型账号和第三方AI客户端界面配置。不能承诺“所有AI一键连接”或“所有网站操作均可实现”。
