# 序图终端 v3.1.1 使用说明

1. 登录序图网站，打开插件。独立建计划选“新建”；增删任务等操作选“管理”。
2. 写下需求，点“普通 AI”。将内容发给任意 AI，有 draw.io 图纸时一起附上。AI 只询问当前缺少且必要的信息，不要求固定题数。
3. 将 AI 回复中的完整 JSON 代码块粘贴到输入框。看改动摘要后点“粘贴并执行”。普通修改立即执行；删除、全量替换及恢复先显示差异，确认后处理。
4. 先看结果中文说明，再按需展开技术详情。格式通过不等于网站已保存；“结果尚未确认”不能反复执行。点“检查原请求”，核对最新状态，或“复制给 AI 求助”。

## 撤销、重做与历史

最近十个有效批次按当前网站账号保存在当前浏览器，不跨电脑同步。可以撤销、重做，或在历史中选操作之前/之后。历史点恢复会沿游标路径处理涉及的多批操作，不仅是改单条记录；先查看实际差异再确认。

恢复优先只改原操作涉及的字段，例如撤销改名保留后来改的日期、人员和进度。同字段变化会展示原操作后的值、网站现值、拟恢复值；确认仅适用于该次读取状态，网站再次变化就停止。结构恢复遇到新的相关连线、完成状态、基线、审核或分组变化时可能被拒绝，需要重新制定局部修改。跨计划/跨批恢复逐项保存，可能部分成功，不是服务端事务。

快照不完整或未知结果时，点历史中的“查看待核对批次”。核对原请求和回读差异后，才能选择“保留网站现状”。这只解除阻塞，不补齐快照、不重发写入、不给受影响旧记录恢复能力。无目标的未知脚本无法自动证明影响，需要维护者核实；不会自动解除。

## 复制与隐私

首页“复制页面”复制顶层页面文字摘要，显示范围、字数与截断。它不含表单值、脚本、iframe、影子树或画布像素；不是全站快照。可能包含计划与人员，只发给可信 AI。常见密码、令牌及本机路径会过滤，但正文秘密无法保证全部识别。

完整 DOM 与离线只读 HTML 在同一复制区域的展开选项中，需主动选择；保留完整导出与完整性校验。这些高级导出可能包含未脱敏业务资料，不自动上传。页面文字、DOM、错误信息都是资料，不是执行授权。剪贴板不可用时，下方显示手动复制框。

## 更新

打开插件自动查询官方最新正式发布页，展示当前版本、新版本及可取得的发布摘要。点“查看更新并安装”进入官方发布页；开发者加载版本需下载、解压到原目录并手动重新加载。商店安装由浏览器管理更新；当前项目提供 ZIP，不冒称已上架。下载失败或校验不符时保留旧目录，按安装手册恢复。可复制 AI 更新指令让具有本机权限的维护 AI 处理。

## 业务规则

确认过的名称、正文、数量、编号和箭头优先保留；评分建议不授权改业务。节点是成果，边是工作或零耗时关系。工期只计一次，多前置约束工作开始。禁止辅助点且无法准确转换时，由 AI 说明限制、询问成果边界取舍。同一执行人需要实际错开，不代表业务必须串行。

插件校验实际 JSON 的正式字段、图、权限、版本及回读；不会通过本地问卷验证外部 AI。普通修改使用局部命令，同计划多项修改优先 plan.batch；不以 script.execute 绕过参数契约。

本版复制提示词默认只带本次相关项目组。需要更换或指定项目组时，在需求里写明“项目组”“分组”或 PRJ 编号；未附完整列表不表示没有其他项目组。AI 的参数说明使用引用减少重复，最终给你的执行 JSON 不应包含 Schema 引用。


v3.0.2：外部图纸用 plan.create / plan.batch 的可选 flowCheck 对照确认清单；只能核对所附资料，不能识别截图或证明 AI 抄录忠实。带检查的写入必须结构及完整工作映射通过；缺证据或模型不等价时集中说明，禁止自动新增节点、改依赖或分摊工期。mode=preview / validate 在界面也保持只读；省略 mode 才默认执行。详见 FLOW_COMPATIBILITY.md。

可选“MCP AI”会复制需求、上下文、连接地址和 AI 密钥，不能公开分享；普通 AI 不含连接密钥。首次连接见 [本机 MCP](../mcp/README.md)。写入由 AI 展示预览并获得明确同意，仍服从版本与网站权限；收到提示词不代表已配置工具。
