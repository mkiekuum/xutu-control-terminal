# 两分钟上手

## 不需要安装CLI的用法

1. 在序图网站登录。插件默认“新建”独立计划；想改已有计划时先选“管理”，并在网站选中目标。
2. 点插件图标，在第一个输入框描述需求，例如新建时写“规划主板首发流程”，管理时写“把连续的两项设计工作合并，保留其他依赖和编号”。
3. 点击“复制 AI 提示词”，粘贴到你使用的AI。当前计划的完整内容默认一起复制，不用勾选授权框。
4. 若AI先提问，先回答；要求它直接在聊天给完整JSON代码块，再粘贴到第二个输入框，点击“执行”。默认直接执行，不需要选择预览或二次确认。
5. 看执行结果；失败原因会直接显示，详细结果可展开复制给AI继续修正。

多个序图网页同时打开时，先在顶部选择要操作的网页。没有选中计划时，复制提示词不会猜测目标，可让AI先生成查询或新建指令。

## 外部AI通过CLI操作

仅适用于可以执行本机命令的 AI 工具。按 WINDOWS_INSTALL.md 安装宿主，在主界面选中网页后展开“更多 → 本地 CLI”，点击“测试本地 CLI”。两步通过后可在本机终端按手册运行 xutu；插件内仅保留测试、诊断复制和帮助链接。多个网页的本机命令务必带实际 --tab-id。

不再提供API Key、模型地址或MCP配置。普通AI聊天网页使用复制粘贴即可。网站权限不足会被拒绝；不能把AI生成建议当成已经保存。

## 给新AI的完整上下文

“复制 AI 提示词”和本机 CLI context 使用同一份 site.context 数据，包含当前计划原文（所有节点、连线、估时、人员、日期）、计划ID/编号/版本、审核记录、基线、完成日期、任务表及canAssign/canComplete权限、预计完成日期记录和依赖检查。还带账号角色、命令参数契约与能力限制，AI不需要从零猜字段。

CLI可运行：

~~~powershell
& "$env:USERPROFILE\.xutu\windows\xutu.cmd" tabs
& "$env:USERPROFILE\.xutu\windows\xutu.cmd" context --tab-id YOUR_TAB_ID
~~~

context是只读快照，带capturedAt、target.version和complete。有部分接口失败或读取时版本改变，complete=false并列出warnings；不能把缺失状态当成未完成/无权限。写入前重新获取context，使用目标当前版本。工作任务表只保留当前计划，不附带其他计划的任务。

## 网站规则与真实评分

提示词与CLI context均包含websiteGuide：双代号网络、节点/工作区别、实线/虚线、三点估时、编号、任务资源、审核和权限规则。siteAnalysis读取当前网页的真实scorePlan/validatePlan及当前评分阈值，包含得分、逐项扣分、总工期、TE/TL、时差、关键边和完成率；读取不到时标记不完整，不编造分数。完整介绍见WEBSITE_GUIDE.md。

优先保证原任务完整、约束真实、编号稳定，再改善评分。固定等待不能改成虚线；不能删除有耗时的工作或修改评分阈值骗分。明确要求保留原数字按天演示时不得转换或缩短；长工期扣分可能无法消除。分数高也不证明人员、截止等现实约束全部可行。

## 2.2新增入口

底部“更多 → 兼容性与排查”默认折叠，打开插件自动只读检查；可重新检查或一键复制脱敏状态。CLI命令为 xutu compatibility --tab-id ID。详细AI规则见AI_PROMPT_GUIDE.md，维护更新见GITHUB_MAINTENANCE.md，新设备与分享见CROSS_DEVICE.md。业务信息不足先问卷；软件维护按既有授权自主执行，不发维护问卷。

## 2.3 软件更新

打开插件自动检查 GitHub 最新正式版，不提供手动检查按钮。展开“更多 → 软件更新”可看版本与检查时间；一键“复制 AI 更新指令”交给有本机工具的 AI Agent。指令不包含业务计划，复制不等于已升级。详见 AUTO_UPDATE.md。

“新建 / 管理”选择用于 AI 提示词，管理包含增删任务、调整结构和进度等，并非仅微调任务内部。指令区始终只接受 JSON；显式 JSON script.execute 沿用浏览器授权和参数校验，无新增确认弹窗。独立 CLI 不受这项界面简化影响。

2.4补充：使用中性表达，严格区分硬约束/质量建议/个人偏好。问卷只收集本次必要信息；仅改名称不追问无关日期人员，建议不生成写指令。更多中可保存账号与场景隔离的偏好。局部改名/重编号、请求追踪、冲突和多步版本规则见LOCAL_EDITING.md；新增功能仅本地模拟验证，真实网站写入未测。
