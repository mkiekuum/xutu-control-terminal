# 两分钟入门

只需浏览器插件和网站账号，不需要 Node.js、命令行或 AI API Key。

1. 打开序图并登录，点工具栏“序图终端”。新建独立计划用“新建”，对现有计划新增、删除、整理等用“管理”。多个网页时选定目标。
2. 在需求框写想做什么，点“复制 AI 提示词”，发给常用 AI。新建或复杂调整先回答插件下方的必要问卷；表达习惯也在里面。已有明确日期/项目组不重复问。填写后保存，再复制给 AI。
3. AI 应直接回复一个完整 JSON 代码块。点代码块复制，粘到插件“JSON 指令”；文件链接、问卷、普通文字不能执行。
4. 查看改动摘要。涉及问卷的方案展开核对人员和工期，点击“已核实这份方案”。点击执行后看结果；格式正确不等于已经写入成功。
5. 需要恢复时用主界面撤销/重做。别人改过的内容不会被旧快照自动覆盖；出现部分成功或未知结果，先读详情，不重复新建。

使用帮助就在主界面。更多只放更新、兼容性、网页复制/保存。网站登录不在插件中输入密码；遇到权限拒绝由网站管理员按真实职责处理。
