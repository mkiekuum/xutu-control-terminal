# 2.2.0范围验收

最新用户范围优先于旧30项与上一轮问卷。未把未实现项改写成完成。

|项目|结果|
|---|---|
|超级详细AI资料|完整计划、网站模型、字段与参数、角色、日期、基线/审核、规划规则、权限及执行边界|
|关键资料不明先问卷|明确提问阶段；只问相关缺项，已确认/可留空不重复问|
|聊天内直接复制JSON|要求单一完整json代码块；文件链接不作指令执行|
|CLI规则一致|context含aiGuidance；复制CLI用法含相同规则与本机入口说明|
|自动兼容检查|打开/切换/连接/上下文读取时检查；真实CLI基础10项通过|
|隐藏的状态复制|底部默认折叠；DOM复制流程验证，报告不带业务数据|
|UI焕新|新步骤卡片、配色/图标/连接状态/折叠菜单；浏览器本地渲染检查|
|分享和新设备|代码无个人路径/账号预设；跨电脑与权限边界手册；未声称所有新设备实机通过|
|维护无人值守|手册要求自主完成修复/测试/发布/安装，可更新UI及功能；真实登录/授权阻塞如实报告|
|真实数据保护|本轮只读，无新建或修改网站计划|

未新增：自动升级器、云同步、后台定时服务、自动业务修复/重放。永久删除/管理员/完整历史等既有接口限制仍存在。第三方AI输出只能通过提示词和指令校验引导，不能保证任意模型全部遵守。
