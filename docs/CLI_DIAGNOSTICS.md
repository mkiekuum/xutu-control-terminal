# 本地 CLI 测试与故障排查（2.3）

插件主界面的指令输入区只接收 JSON 或 Markdown JSON 代码块。CLI 文本、JavaScript 源码和文件路径不能直接粘贴执行。本机终端的 xutu 命令、JSON/JSONL 批量执行、context、preview/validate、doctor 均继续支持。

## 在插件里测试

1. 在主界面选择要测试的序图网页。只有一个网页时自动选中；有多个网页时必须明确选择，不会默认使用第一个或当前激活网页。
2. 展开“更多 → 本地 CLI”，点击“测试本地 CLI”。
3. 分别查看两段结果；只有两步都通过才显示整体成功。
4. 需要反馈时点击“复制诊断结果”。安装和故障排查链接保留在同一区域。

测试区没有独立的网页选择器、命令输入框或“复制 CLI 用法”按钮。切换主界面目标会清除旧测试结果；测试期间目标改变也不会把旧结果当作新目标的成功。

## 两步实际做什么

第一步通过 Native Messaging 连接宿主，并发送一个新的 ping 等待宿主响应。连接记录或上一次成功不能代替本次响应。

第二步让宿主启动实际 Node CLI 子进程，只执行固定的 `site session --tab-id 已选ID`。该命令通过正常本机认证管道 → 宿主 → 扩展后台 → 所选序图网页，进行一次轻量只读会话查询。不会扫描其他网页，也不创建、修改或删除计划。测试后宿主桥接保持连接，本机 CLI 可继续使用。

第一步失败时第二步标记“未执行”；第一步通过但第二步失败时保留宿主通过状态，并显示网页阶段的原因。未选目标时两步均不执行，提示返回主界面选择。过旧宿主不支持这套探针时明确提示升级，不冒充测试通过。

## 常见结果

| 结果 | 处理 |
| --- | --- |
| 未找到宿主 | 按 Windows 安装手册安装整包宿主；扩展 ID 从浏览器扩展详情复制 |
| 宿主连接失败 | 核对 Node.js、实际扩展 ID、宿主注册和安装目录 |
| 宿主版本过旧 | 更新 Windows 整包；重新加载扩展后再测试，使旧进程退出并加载新版 |
| 宿主响应超时 / 中断 | 检查本工具连接，关闭再打开插件；不要批量结束 Chrome 或 Node |
| 本机 CLI 启动失败 | 检查 Node.js 和完整 native-host 目录是否仍在原安装位置 |
| 本机桥接认证失败 | 按安装手册重新注册；不要复制另一台电脑的认证配置 |
| 网页未登录 | 在主界面选中的序图网页登录后重试 |
| 网页权限不足 | 使用当前账号真实权限，不伪造身份 |
| 选中网页不存在 | 回主界面重新选择已打开的序图网页 |
| 网页通信失败 | 刷新选中网页后再测 |
| 查询超时 / 网站服务器错误 | 检查网络与网站状态，稍后重试 |
| 未识别错误 | 错误已脱敏；保留版本与时间，按本手册定位，不能据此声称业务执行成功 |

## 诊断复制范围

只包含插件版本、测试时间、两段状态、整体结果和固定白名单中的脱敏原因。不复制计划内容、账号姓名、网页 ID、凭据、管道认证值、本机绝对路径、原始进程 stderr 或服务器错误正文。真实会话数据只用于完成查询，不进入返回的诊断报告。

本机 `doctor` 输出与这里的脱敏报告不同，可能含本机路径；不要直接公开粘贴原始本机诊断、配置文件或完整业务 context。

## 本机 CLI 示例仍可使用

先按 [Windows 安装说明](WINDOWS_INSTALL.md) 安装，再在插件测试建立桥接。PowerShell 示例：

~~~powershell
$xutuCli = Join-Path $env:USERPROFILE '.xutu\windows\xutu.cmd'
& $xutuCli doctor
& $xutuCli tabs
& $xutuCli context --tab-id YOUR_TAB_ID
& $xutuCli exec "plan list --mode preview" --tab-id YOUR_TAB_ID
& $xutuCli run --file command.json --tab-id YOUR_TAB_ID
& $xutuCli run --file batch.jsonl --jsonl --tab-id YOUR_TAB_ID
~~~

YOUR_TAB_ID 是占位值，要用 tabs 返回的实际值。本机 CLI 的网页发现能力保留；插件“测试本地 CLI”本身不会调用 tabs。

## JSON 中显式执行脚本

JSON 的 `script.execute` 保留，沿用浏览器用户脚本授权、world/source 参数校验及后台执行逻辑，不新增确认弹窗。纯 JavaScript 输入已从插件移除。本机 CLI 的 js 命令也保持原有行为。

AI 提示词仍不列出脚本参数契约，并要求不使用 script.execute 绕过业务命令或权限。移除 JavaScript 输入方式不等于删除后台脚本能力。

## 验证范围

本版使用本地模拟覆盖失败分段与脱敏，使用真实宿主进程、CLI 子进程和认证管道对接模拟网页回读。实际登录浏览器中的新版测试需用户重新加载后执行；不将模拟网页当作真实站点验收。业务写入回归仅在本地契约模拟运行。
