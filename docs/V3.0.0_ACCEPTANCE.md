# v3.0.0 升级验收（2026-11-12）

## 根因与实现

- 旧恢复要求完整快照及 revision 完全一致：无关日期/布局变化也阻断。现按原操作前后差分，对最新服务器数据做字段级三方合并；不猜版本，不覆盖无关字段。新增/删除节点和连线按稳定标识处理，重新检查有效图；相关远端连线、进度、基线或审核/分组冲突保守拒绝。
- 旧回读将 positions 差异与业务丢失混为一谈。现业务字段仍逐项严格验证，非显式布局变化单独警告；明确编号映射等布局意图仍严格检查。删除节点同时清理它的坐标。历史使用真实回读快照，普通文字撤销不回滚网站附带的自动布局。
- 普通 plan.get 缺 targetId/afterVersion，导致 versionFrom 被执行器拒绝。已返回真实读取版本，并保留目标匹配、成功回读条件。
- 未知批次在没有业务差异时曾丢失核对目标。现在保留目标和原请求关联。解除必须先查看最新差异及匹配审阅摘要；不补造快照，不重放未知请求，不恢复受影响记录的可撤销资格。

## P0 验收

十批上限、连续撤销/重做、新编辑截断重做、IndexedDB 重启、账号隔离、跨计划恢复已测试。新三方合并覆盖远端日期/人员/进度/基线/布局保留、同字段冲突无写入、确认覆盖、过期确认拒绝、跨多个历史点恢复、结构不安全拒绝、部分超时、提交窗口版本冲突及独立回读。原有单批一次提交、无变化不保存、重复请求、防未知重放继续通过。

恢复先预览再由使用者确认。普通编辑不新增确认；删除/全量替换/恢复有具体影响预览。UI 提供原请求查询和求助复制。部分成功保留成功目标，不冒称服务端事务。

## P1 验收

首页三步流程、需求框、复制给 AI、JSON 执行、撤销/重做/历史、复制页面及可展开帮助保留。页面摘要显示范围与截断，过滤常见秘密；完整 DOM/离线 HTML 在更多。更新版本来自官方 latest 跳转，摘要为发布页纯文本，不能成为执行指令；正文无法取得不影响已核实的版本结论。安装按开发者 ZIP 的真实能力说明。

draw.io 只增强提示词/网站说明：缺图不假装读图、模糊关系先问、无固定题数、保留确认表格、对象 ID 不当业务编号、多前置限制工作开始、单次工期、资源约束与业务依赖分开、只用正式契约。回归检查提示词和合成 JSON 样例；没有调用外部 AI 做视觉评测，不能据此保证任意 AI 理解正确。

## 测试证据与边界

- 命令：node --test --test-concurrency=4 tests/*.test.js。一次默认并发运行因 Windows spawn EPERM 启动限制失败，限制并发后完整重跑通过。
- Node 单元、JSDOM、fake-indexeddb、模拟接口与本地 HTTP 契约测试：140 项通过，0 失败、0 跳过。
- 独立 headless Chrome 157：12 项新增 UI 检查通过（撤销预览/恢复、重做、冲突展示/取消、页面复制、删除预览、未知状态、原请求诊断、解除确认、不可恢复按钮禁用、求助复制）。普通两项修改仍只有一次模拟 POST、一次版本增长。
- 离线约 1.3 MB 合成 HTML 保持 SVG/表格/表单静态值/影子树；CSP 阻止注入脚本与网络写入；缺失资源明确列出。
- 未操作真实业务计划、未登录生产站写入、未操作物理鼠标。没有验证用户已安装扩展重载、真实系统剪贴板、其他设备或 Edge 安装。隔离浏览器页面模式不冒充扩展安装验收。
- 无服务端事务、服务端全历史、永久删除、跨设备去重/历史同步保证。任意脚本、审核及权限配置等无法完整安全逆转的操作继续标不可恢复。

## 交付与发布约定

源码在本仓库；dist 提供 v3.0.0 chrome.zip、source.zip、SHA256SUMS。使用既有 release.yml 生成草稿附件，通过同一 tag 的 CI、下载与 SHA256 核验后转正式发布；不覆盖 v2.5.2。实际 commit、推送及 Release 状态由交付回复和 GitHub 回读确认，本文不把发布准备等同已发布。

升级后唯一必要人工步骤：在现有扩展管理页重新加载原目录中的“序图终端”，确认界面版本为 3.0.0；未获此真实结果前不宣称已加载。
