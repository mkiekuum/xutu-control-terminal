# v3.0.2 外部流程图转换修复与验收

## 问题归属与针对性修改

| 问题 | 归属 | 实际修改 |
| --- | --- | --- |
| 把辅助开始点当默认、零耗时分类与连线混淆 | AI 规则 | 删除默认补点表述，先尊重禁止新增；区分 outcome/category/event/auxiliary |
| 并行变串行、改接分支、只合并少量内容却重写结构 | AI 规则与缺少原图对照 | 保留确认后的节点/正文/直接箭头，执行前按清单比较，未授权差异不提交 |

| 本地检查通过冒充业务/网站成功 | 展示 | 普通中文说明来源及未核实范围，详细差异可展开复制 |

## 新增可执行能力

plan.create / plan.batch 可选参数 flowCheck 定义确认后的完整目标清单、直接箭头、工作与连线及三点估时映射。运行时校验最终候选图，不是只检查提示词。批量仍本地变换，一次版本保护提交，失败零网站写入；回读、历史、防重复逻辑不替换。

结果包含新增/删除节点、改名/正文、直接箭头增删、祖先前置变化、逐工作估时变化。多前置只接成果却没有约束工作开始、重复工作映射、遗漏正工期边、类别节点冒充实际成果等会拒绝带检查的提交。没有完整工作映射时只能查看预览，不宣称排程正确。

没有 flowCheck 的旧指令保持兼容，新建/批量结果明确标记原图与工作映射未核实。插件不能从缺失截图或任意自然语言推导授权，也无法证明 AI 抄录的清单忠实。不得把清单反向改为错误候选图以消除报错。

本版没有图纸解析器、自动重绘、辅助节点折叠或新网站数据模型；没有恢复 CLI、Native Messaging、问卷/偏好、外观、AI Key 或 MCP。

## 回归范围与结果

- 162 项 Node 测试通过，0 失败、0 跳过。其中新增 15 项覆盖图纸对照、工作映射、只读模式、API 最终提交门槛、版本冲突、回读失败、去重和旧指令兼容。其余为既有单元/模拟接口/本地 HTTP/DOM/存储回归。
- 公共回归使用脱敏后的 17 节点、19 箭头拓扑：独立分支保持独立，两个依据共同汇入指定成果；保留后续成果链；两路依据仍接最终汇合，不改接中间分析；三个原分类保留；26–29 不自动恢复。
- 用户最终 draw.io 仅在本机解析核对原始结构与标签留存，原文件和真实业务正文未放入 Git。图中文字的标题/正文分配及完整工作估时没有重新确认；本地夹具使用占位名称和零工期仅检查拓扑，不是建议工期，不是可执行业务方案。明确标记工作依赖/工期未核实。
- 隔离 Chrome 157 回归通过：显式 preview 没有 POST，图纸差异拒绝且可展开/复制；既有 12 项撤销、重做、冲突、删除确认、未知结果诊断及复制帮助回归通过；两个修改仍只产生一次模拟 POST 和一次版本增加。没有接管用户浏览器或真实鼠标。
- 浏览器首次启动超过原 10 秒探测窗口；独立启动诊断确认可启动，将测试探测上限改为 30 秒并检查子进程退出，再运行通过。只影响 QA 工具。
- 公开网站计算机制沿用前一轮下载的原生函数研究结论；本轮没有生产网站写入，未做真实安装/重载、系统剪贴板或任意外部 AI 回答的效果验收。
