# 自动版本检查与 AI 更新指令

打开插件自动请求官方 GitHub /releases/latest 网页。只接受 HTTP 200 且最终地址为本仓库合法 /releases/tag/v数字版本；404 有 HTML 也不算存在。HEAD 不受支持时回退同地址 GET。不读 GitHub API 或自定义更新文件。成功缓存两分钟，失败三十秒，并发合并；失败明确显示无法确认。

“更多”可复制 AI 更新指令，包含当前版本、扩展 ID 与官方来源，不含计划/账号。交给能操作本机的 AI，它按 [维护手册](GITHUB_MAINTENANCE.md) 和 [换电脑手册](CROSS_DEVICE.md) 完成下载、SHA256、备份、替换完整 UI/功能、测试和加载验证。普通升级不授予上游发布或生产写入权限。

开发者加载的扩展不能绕过浏览器强制许可自我替换，安装重载必要时由本人完成。v2.5 没有 CLI、自更新守护进程或远程代码下载执行器。正式发布使用原有 Release 渠道及 SHA256SUMS；没有新增元数据服务或签名系统。
