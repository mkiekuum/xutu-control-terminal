# v2.5 网页原文与离线 HTML

入口在“更多 → 复制网页与离线保存”，只处理主界面明确选中的序图标签。先检查当前网站会话，不读取其他网站、窗口或浏览历史。

## 完整网页 DOM

“复制完整网页 DOM”读取运行时 document.documentElement.outerHTML，保持原文，不脱敏、不替换截图。每块 131072 个 JavaScript 字符，组装后核对总字符数、UTF-8 字节数及 SHA-256；任一不匹配不交付截断结果。缓存限两份、五分钟，传完释放。

原始 outerHTML 不是整个浏览器内存：不含 Shadow DOM 内部树、仅保存在 JS property 的值、跨域 iframe 文档或关闭的影子树。剪贴板失败时显示完整手动复制区，并可下载完整原文 HTML；不会假报复制成功。

原文可能含公司计划、人员和页面中的其他私密内容。仅用户主动复制或保存，不上传 GitHub、云日志或 AI，不进入执行日志与十步历史。原始 HTML 保留原网页行为，**不应作为安全离线阅读文件打开**；离线阅读使用下面的独立功能。

## 离线只读 HTML

克隆 DOM；保存输入框展示值、开放影子树、可读取画布、SVG、表格、可见弹窗等。尽量内联同源 CSS、图片和字体。移除脚本、iframe/object/embed、事件处理、表单动作、外链和刷新；控件禁用、表单 inert，并加入禁止脚本、连接、提交及框架的 CSP。不会登录网站或提交业务。

单资源上限 8 MiB、二进制内联总预算 32 MiB；资源下载只使用原站同源 GET。跨域资源、嵌套 CSS import、不可读取画布、外部 SVG 引用等写入 missingResources[]，在导出详情展示。字体/CSS 兼容、动画、闭合 Shadow DOM、虚拟列表未渲染内容不能保证还原；这是静态快照，不是可继续编辑的公司应用。

## 验证证据

合成 DOM 1,300,902 字节逐字节一致；离线产物 1,301,383 字节。在独立、未登录的 Chrome 157.0.8103.51 配置中，通过 CDP 离线网络模拟打开本地文件：标题、SVG、表格、dialog、open shadow 和输入属性值可见，表单 disabled/inert，注入的测试脚本被 CSP 阻止，网络 POST 为零。缺失两项外部 CSS/import 已报告。

这是实际 Chrome 渲染的合成页面验收，不是当前公司页面导出的实测；真实扩展剪贴板、浏览器下载提示和公司页面资源未测试。复现：node tools/verify-browser.mjs ABSOLUTE_CHROME_PATH PRIVATE_OUTPUT_DIR，仅启动隔离 headless 配置，不操作真实鼠标或已登录浏览器。

高级 JSON 接口 site.html.begin/chunk/release 是扩展本地导出路由，不是服务器 API。每个独立导出请求不进入去重日志，begin 返回元数据而不是整份原文；普通用户应使用上述按钮自动收齐并校验，不能只复制第一个 chunk 当作完整网页。
